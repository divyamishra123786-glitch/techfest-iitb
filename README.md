# 🌌 Techfest, IIT Bombay — An Aetherial Renaissance
> **Official Landing Page Ideation for Asia's Largest Science & Technology Festival**  
> *Indian Institute of Technology Bombay (IIT Bombay)*

---

## 🏛️ Theme: An Aetherial Renaissance
> *"Where ancient Da Vincian polymathic curiosity converges with cutting-edge artificial intelligence, quantum cognition, combat robotics, and interstellar exploration."*

This landing page is ideated and crafted for **Techfest, IIT Bombay**. In strict adherence to design requirements:
- **Zero 3D assets** (100% 2D HTML5 canvas, responsive procedural SVG, modern CSS, and high-fidelity 2D digital art).
- **Rich Futuristic Aesthetics**: Neoclassical cyber-renaissance dark theme, glassmorphic floating telemetry, bioluminescent neon accents, responsive typography, and dynamic micro-interactions.

---

## ✨ Key Features & Architecture

### 1. 🌌 2D Celestial & Neural Constellation Canvas
- Lightweight 2D canvas animation simulating celestial orbits and neural networks.
- Reactive particle gravitation towards cursor with dynamic proximity-based line rendering.
- Zero WebGL or 3D asset overhead — ultra-fast 60 FPS performance on all mobile and desktop devices.

### 2. ⏳ Live Festival Countdown & Dynamic HUD Telemetry
- Real-time countdown timer to Techfest 2026 (Days, Hours, Minutes, Seconds).
- High-tech HUD telemetry card framing custom Renaissance artwork with coordinate and version indicators.

### 3. 📊 Animated Impact Metrics
- Interactive counter displaying Techfest's global reach:
  - **175,000+** Footfall & Attendees
  - **2,500+** Participating Colleges
  - **₹45 Lakhs+** Total Prize Valuations
  - **60+** International Nations Represented

### 4. ⚔️ Flagship Verticals & Competitions Showcase
- Interactive category filtering:
  - **Competitions**: *Robowars* (₹10,00,000 pool), *ZeroCode AI Multi-Agent Sprint* (₹3,50,000 pool), *Drone Racing Grand Prix* (₹5,00,000 pool).
  - **Workshops**: *Quantum Computing & Qiskit Masterclass* (IITB Certified).
  - **Tech Expo**: *International Next-Gen Bionics & Humanoids Showcase*.
  - **Technoholix**: *500-Drone Aerial Formation, Laser Art & EDM Pro-Nite*.
- Express interactive modal for detailed rules, eligibility, team size, and zero-fee registration.

### 5. 💻 Interactive "Aether Terminal" CLI Emulator
- Built-in cyberpunk command-line interface.
- Supports commands: `help`, `theme`, `events`, `robowars`, `prizes`, `schedule`, `stats`, `ca`, `matrix`, `easteregg`, `clear`.
- Quick-action command chips with instant responses.

### 6. 📅 3-Day Itinerary & Schedule Matrix
- Interactive day tabs (**Day 01: Genesis**, **Day 02: Zenith**, **Day 03: Transcendence**).
- Venue markers, timing slots, and event categorization tags across IIT Bombay's Powai campus.

### 7. 🔊 Procedural Web Audio API Sound Synthesizer
- Built-in sci-fi UI audio engine generating subtle interactive clicks, hovers, and low-frequency ambient synth drone.
- 100% code-synthesized with zero external audio file dependencies.
- Toggleable sound button in navbar with visual audio-wave pulsation.

### 8. 🎓 Campus Ambassador (CA) Portal & Hall of Luminaries
- Features legendary past speakers including **Dr. A.P.J. Abdul Kalam**, **Sophia the Robot**, and **Wing Cdr. Rakesh Sharma**.
- Dedicated Campus Ambassador section detailing student leadership perks, accommodation, and verified IIT Bombay certificates.

## 🚀 Quick Start & Local Preview

### Running Locally with Node.js
```bash
# In the project directory:
node server.js
```
Open your browser at: **`http://localhost:4173`**

Or simply double-click **`index.html`** in any web browser!
